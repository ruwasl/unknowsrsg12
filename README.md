# Grand Theft Auto 1 & 2 — Classic 2D Top-Down Web Edition

A retro browser-based 2D top-down arcade game inspired by classic **GTA 1** and **GTA 2** gameplay, built using **HTML5 Canvas**, **CSS**, **JavaScript**, and the **Web Audio API** with zero external dependencies or build steps.

## Features
- **Classic Top-Down & Pseudo-3D Roofs:** Dynamic speed-based camera zoom and parallax building rooftops.
- **Carjacking & Traffic AI:** Hijack street vehicles, sound car horns, dodge traffic, and trigger explosions on heavy damage.
- **GTA 2 Gang Respect & Payphones:** Track respect for **Zaibatsu**, **Loonies**, and **Yakuza**, and answer ringing payphones for jobs.
- **Wanted System & Law Enforcement:** Build up wanted stars, evade police cruisers and officers, and watch out for **WASTED** or **BUSTED** states.
- **Weapons & Pickups:** Switch between Fists, Pistol, Dual Uzi, Flamethrower, and Rocket Launcher, and collect health, armor, and ammo pickups.
- **Retro Details:** Classic green pager alerts, radio station switching, Elvis roadkill bonus alerts, and Web Audio synthesized sound effects.

## Controls
- **W / Up Arrow:** Walk forward / Accelerate
- **S / Down Arrow:** Walk backward / Brake & Reverse
- **A / D or Left / Right Arrow:** Turn / Steer
- **Enter / F:** Enter or exit a vehicle
- **Space / Left Click:** Attack / Shoot / Honk horn
- **Q / E:** Switch weapons
- **Tab:** Classic GTA burp/fart sound
- **R:** Switch radio station

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Brave).
